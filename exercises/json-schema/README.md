# JSON Schema

You start with a tiny set of JSON rules and gradually move to the larger EGA v2 schemas stored in several files.

| Exercise | Topic |
| --- | --- |
| [1](01-validate-a-minimal-entity.md) | Validate a minimal entity |
| [2](02-break-and-repair-data.md) | Break and repair data |
| [3](03-follow-an-internal-ref.md) | Follow a `$ref` inside one schema |
| [4](04-resolve-a-relative-ref.md) | Use `$id` to find another schema file |
| [5](05-open-and-closed-object-schemas.md) | Open and closed object schemas |
| [6](06-test-entity-identifiers.md) | Test entity identifiers |
| [7](07-reuse-a-standard-schema.md) | Reuse one small definition (optional) |
| [8](08-reuse-beacon-cohort-rules.md) | Reuse Beacon Cohort rules (optional) |
| [9](09-choose-a-schema-version.md) | Choose a schema version (optional) |

Exercises 1–6 are the main route. Exercises 7–9 are useful when connecting EGA metadata to another system.

## Optional extensions

Exercises 7–9 are the optional JSON Schema extensions mentioned in the [root workshop route](../../README.md).
